# Cartellina — download

**Cartellina** aiuta a tenere in ordine la burocrazia della salute: email sanitarie, documenti, calendario, farmaci e promemoria. I dati restano sul tuo telefono.

## App Android (APK)
**[Scarica Cartellina.apk](https://github.com/rupi7800-blip/Cartellina-/releases/download/android-latest/Cartellina.apk)**

1. Scarica il file sul telefono (Android 6 o successivo) e aprilo.
2. Quando Android lo chiede, consenti l'installazione di app da questa fonte. Se compare un avviso di Google Play Protect, scegli «Installa comunque».
3. Gli aggiornamenti si installano scaricando il nuovo file e aprendolo: i dati restano.

## Versione nel browser
Apri il [sito](https://rupi7800-blip.github.io/Cartellina-/) e, dal menu del browser, scegli «Aggiungi a schermata Home» (funziona anche su iPhone).

## Cose da sapere
- Cartellina **non è un dispositivo medico** e non sostituisce il parere del medico. In emergenza chiama il 112.
- I dati (appuntamenti, documenti, email lette) sono salvati **solo sul telefono**; con il PIN sono cifrati. L'app non ha un server né account online. Per sapere se c'è una versione nuova legge un piccolo file da questo sito: GitHub vede che l'app è aperta (indirizzo IP e orario), non i tuoi dati.
- L'app installata dal browser e l'APK non condividono i dati: per passare dall'una all'altra usa *Impostazioni → Privacy e dati → Esporta / Importa*.

Questo repository contiene solo i file pubblicati (sito e APK). Il codice sorgente non è qui.
